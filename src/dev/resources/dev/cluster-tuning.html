마커 클러스터 튜닝

로컬 DB 장소로 실제 서버 계산을 돌려 봅니다(비로그인 기준). "재검색"을 누르면 지금 화면 범위로 검색하고, 확대·축소는 앱처럼 요청 없이 단계만 바꿉니다. 클러스터를 누르면 bounds로 확대됩니다.

target-columns — 클수록 칸이 작아져 원이 많아짐(실제 약 0.7~1.4배)
no-cluster-width(3857 단위) — 화면 폭이 이 이하면 모두 개별 표시
cluster-inset-ratio — 칸 가장자리에서 이 비율 안쪽에만 원을 그림
max-cell-level — 한반도 전체 화면에서 쓰는 칸 크기
